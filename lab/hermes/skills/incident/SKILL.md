# incident

## Do

1. Classify: shipping / marketplace / accounting / compliance / mailbox.
2. Prefer **NEEDS_CONFIRMATION** / human lane over silent fix.
3. Never auto-clone Mastersheet rows marked `NEEDS_CONFIRMATION`.
4. Log what was checked (simulated vs live read).

## Do not

- CE sticker peel workarounds.
- Spend money or commit invoices without APPROVE.
