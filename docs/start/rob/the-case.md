# The case in one breath

> WiseQ already runs a remarkably modern stack — **Shopify with a custom B2B layer, ChannelDock (including native bundles), FiveX, e-Boekhouden, three bol accounts, and live agentic-commerce endpoints.** The gap isn't tools; it's **orchestration**. School orders eat four-hour mornings. Purchase averages still live in Excel. Shipping-rule mistakes create ungefrankeerde zendingen. Bol seller-score work is manual. Marketing underuses the site's potential.
>
> We propose **one AI-operations seat first** — Hermes Desktop on the machine you already leave on — that reads mailbox / ChannelDock / bol / e-Boekhouden **read-only**, drafts school-order and shipping digests for your approval, then grows into always-on jobs once the shadow demos earn trust. **Nothing is ripped out.** Every phase is additive and measurable. Full client map: [doc 30](../../10-client/01-complete-dossier.md).

## The case in one page

| The gap we found | The evidence | What we build | The measurable target |
| :--- | :--- | :--- | :--- |
| **School orders eat 4-hour mornings** | Founder-confirmed (working session) — **hypothesis** until timed on ≥10 real orders | School pipeline assist: email → **e-Boekhouden** offer/invoice → ChannelDock booking draft | **4h → &lt;15 min** human touch (Gate 0.3 calibrates) |
| **Bundle / purchase trail is still human** | Meeting: recombination pollutes “what we really sell”; manual: book 300-series as ChannelDock **bundles**, bijmaken = failure | Keep CD bundles; add **EAN registry + purchase-intel** so Excel averages die | Clean purchase data; fewer bijmaken events |
| **0 of 230 SKUs carry an EAN in Shopify export** | Programmatic Shopify audit (Oct 21) | EAN/GTIN backfill + GS1 — **€225/yr** for the catalog | 230/230 registered |
| **77 bundle-products had no machine-readable map** | Same audit — mapping lived in memory | Decoded **bundle spine**: 114 components + 25 bundles (research SoT; reconcile to live CD in Gate 3) | Fully decomposed + CD-aligned |
| **Purchase data assembled by hand in Excel** | 6-month rolling average per EAN | Nightly purchase-intelligence job (after read exports) | Daily, automatic, correct |
| **Ungefrankeerde / wrong shipping profiles** | Ops manual + Mastersheet templates | Template validation + ChannelDock queue digest | Fewer ungefrankeerd tickets |
| **Review / seller-score work is manual** | Manual prioritises **bol ≥9**; Trustpilot only **13 / 4.5** organic (Oct 23) | Bol-first draft follow-ups (**human send**); Trustpilot invites second | Seller score defended; honest review growth |
